## Context

当前模型选择器只保存每个智能体最近使用的偏好，聊天历史没有逐次切换记录。用户希望像 ZCode / WorkBuddy 一样，在会话内看到每次模型切换，刷新或重启后仍可查看，连续 A → B → A 也应留下两条记录。

本次建议覆盖 **通过 Codeg 模型选择器及共享配置接口发起的主动切换**，适用于桌面、Web 和各智能体适配器。CLI 内 `/model`、智能体自主切换及既有原生历史的追溯识别暂不纳入；这是未收到范围选择后的建议默认值。

## 用户可见行为

- 在聊天时间线显示独立、低干扰的提示行：**模型已切换：A → B**，带发生时间；模型名称使用切换时保存的名称，缺失则显示原始 ID。
- 每次有效切换单独保留，不合并 A → B → A。重复选择同一模型不新增记录。
- 以智能体响应为准。确认切换到不同模型时记录实际结果；仅接受请求但未确认实际模型的旧协议显示“已请求切换到 B”，不误报为已生效。失败、拒绝、未执行不生成成功记录。
- 初始化、恢复偏好、模型目录刷新和重复配置广播不产生切换记录。
- 已有会话重连后、发送新消息前的切换也归属原会话。新草稿首次发送前的切换暂存在连接中，创建会话时写入；未创建会话便丢弃的草稿不生成历史会话。
- 提示行不计入用户/助手消息数、token 统计，不进入发送给模型的提示内容。

## 实现方案

### 1. 会话级持久化记录

新增 `model_switch` 数据模型、SeaORM entity/service 和迁移，并在相应 `mod.rs` 注册。沿用 `tool_approval` 的会话关联与历史补充模式，但使用追加记录及稳定 UUID 去重。

记录包含：会话、外部 session/connection 身份、顺序、时间、配置项、前后模型 ID 与名称快照、请求值、确认状态及历史位置锚点。保留完整 provider-qualified ID。记录随会话删除规则处理，并纳入现有数据库备份。

关键文件：
- `src-tauri/src/db/entities/`、`db/service/`、`db/migration/` 下新增对应文件。
- `src-tauri/src/models/` 与 `src-tauri/src/acp/types.rs` 定义共享记录、消息块和事件。

### 2. 在真正处理切换的位置记录

复用 `src-tauri/src/acp/connection.rs` 的 `set_config_option_for_agent` 和 `SetterOutcome`，统一覆盖空闲与生成中的切换。

- 执行前读取后端当前模型及名称，执行后按 `Confirmed / Accepted / NotExecuted / Refused / Err` 决定是否记录以及措辞。
- 使用模型配置项识别规则，避免把推理强度、模式变更当成模型切换；标准 `model` 项优先。
- 引入连接可调用的持久化服务：已有会话等待幂等写入成功后再发布持久记录事件，不依赖可能丢失的广播订阅落库。
- 数据库写入不持有 SessionState 锁。持久化失败保留可重试记录并明确报告保存失败，不能将它伪装成模型切换失败或静默丢弃。
- 在 `manager.rs` 补齐已有会话绑定、草稿记录归档，以及 fork/会话身份变化时的记录归属。真正分叉时原历史保留完整记录，新分支仅继承分叉点之前的记录；同一会话的 ID 别名或 transcript rollover 保留连续历史。
- `session_state.rs` 快照携带尚需实时恢复的记录，使断线重连不漏显示。

### 3. 历史加载与实时展示共用记录身份

在 `src-tauri/src/commands/conversations.rs` 的共享历史处理路径，将记录投影成带专用 `model_switch` block 的 system turn。合并必须发生在分页和指纹计算之前，使完整详情、历史页和 outline 使用相同坐标。

- 保留原生消息顺序和 ID；使用所在回合/相邻消息锚点及事件顺序插入，时间仅作为回退，不对原生历史全局重排。
- 生成中切换的提示位于当前回复之后、下一轮之前；多条切换保持命令处理顺序。
- 前端 `src/contexts/acp-connections-context.tsx` 消费专用事件，`src/stores/conversation-runtime-store.ts` 增加按记录 ID 幂等更新、快照恢复及历史去重。
- 在最终时间线组合时放置事件，避免直接追加到 persisted/local 数组造成错序；历史补入后清理对应实时副本，纳入现有缓存依赖。
- 不通过每次切换强制重载会话，避免破坏尚未写完的本地回复。

### 4. 提示行、导出与国际化

- 更新 `src/lib/types.ts` 和 `src/lib/adapters/ai-elements-adapter.ts`，显式支持新消息块。
- 在 `src/components/message/message-list-view.tsx` 复用独立 compaction 行的外层时间线结构，实现模型切换提示；不并入助手回复或通用系统警告框。
- 保持稳定行 key、滚动锚定、上一条用户消息导航，以及末尾回复的分叉操作。
- `src/lib/export-conversation.ts` 的 Markdown/HTML 导出包含切换记录。
- 在 `src/i18n/messages/` 十种语言中增加一致的文案键；模型名称本身不翻译。
