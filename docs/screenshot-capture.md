# 截图捕获与标注

对话输入框“+”右侧有相机按钮，悬停或点击可选择：

- **截图**：保持窗口可见，冻结屏幕并进入框选。
- **隐藏窗口截图**：先隐藏主窗口再截图，结束或取消后恢复主窗口。

## 框选与标注

拖拽框选后，工具栏直接显示在亮区旁，无需打开另一个编辑窗口。

- **调整大小**：将鼠标移到选区四角或四边的手柄上，拖动调整边界。
- **移动亮区**：使用“选择”工具，在亮区空白位置按住拖动；抓住已有标注时则移动该标注。
- **重新框选**：从暗区开始拖动可重新选区。标注保留在原始画面位置，输出按最终选区裁剪。
- **标注工具**：画笔、矩形、椭圆、箭头、文字、马赛克、序号，支持五色色板、撤销和重做。
- **Esc**：先取消正在输入的文字或拖拽，再次按下可取消整个截图。

## 截图输出

- **勾选 / 复制**：将带标注的选区复制到系统剪贴板并结束截图。不会自动添加到 AI 会话；需要时在聊天、文档或其他应用中粘贴。
- **保存**：打开保存对话框，选择路径后保存为 PNG。保存或取消路径选择后仍可继续编辑。
- **图钉**：将当前选区钉在桌面，结束截图。钉图窗口始终置顶，可拖动位置，单击图片关闭；关闭时清理临时图片。

## 平台说明

- 当前截图功能支持 **Windows 桌面版**。
- macOS / Linux 截图支持尚未实现；Web 和远程工作区不显示截图入口。
- 本机安装包用于本地验证，不代表已发布新版本。
