# 截图捕获与标注

对话输入框"+"右侧有一个相机图标按钮，悬停打开菜单：

- **截图**：保持当前窗口不动，屏幕全屏变暗进入选区。
- **隐藏窗口截图**：先隐藏 Codeg 主窗口（约 300ms）再进入选区，适合截取被主窗口挡住的内容，完成后窗口自动恢复。

## 选区

覆盖屏幕的冻结画面上直接拖拽出矩形选区，选区角落实时显示宽×高（W×H）：

- **Enter / 双击**：确认选区，进入标注编辑器。
- **Esc**：取消本次截图。

## 标注编辑器

确认选区后打开编辑器，工具栏包含：

- **选择**：拖动已画的标注调整位置。
- **画笔 / 矩形 / 椭圆 / 箭头 / 文字 / 马赛克 / 序号**：在图上直接绘制；"序号"每次点击自动递增编号。
- **裁剪**：拖出新的裁剪框后应用，可微调画面范围（取消裁剪回到原样）。
- **撤销 / 重做 / 清空**：管理标注历史。
- **色板**：5 种标注颜色可选。

点击"附加"把标注后的图片作为图片附件放进输入框，随消息一起发送；"取消"则丢弃。

## 平台说明

- **Windows**：完整支持。
- **macOS / Linux**：暂不支持——按钮可见，点击会得到"暂不支持"的提示。
  - **macOS**：按仓库安全架构，屏幕捕获 API 只允许 computer-helper sidecar 持有（TCC 授权按进程归属，不能落在 codeg 本体），截图需改走 helper 捕获通道，后续单独排期。
  - **Linux**：xcap 的 Linux 后端依赖新版 PipeWire 头文件，Ubuntu 22.04 编译不过。
- 仅桌面模式可用（服务器/Docker 部署的 Web 端不显示该按钮）。
