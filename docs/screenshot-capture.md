# 截图捕获与标注

对话输入框“+”右侧有相机按钮，悬停或点击可选择：

- **截图**：保持窗口可见，冻结屏幕并进入框选。
- **隐藏窗口截图**：先隐藏主窗口再截图，结束或取消后恢复主窗口。

## 框选与标注

进入截图后可以单击选择整窗，也可以拖拽自由框选。选定后工具栏直接显示在亮区旁，无需打开另一个编辑窗口。

- **悬停选窗**：尚未选区时，移动鼠标会预览鼠标下最前方可见窗口的边界；单击即可选中，按住拖动则自由框选。预览不会切换窗口焦点或移动原窗口。
- **多屏与重叠**：窗口边界随画面冻结，重叠处优先选择前方窗口；跨屏窗口只选择当前屏幕内的部分。隐藏、最小化窗口和桌面任务栏不参与识别。图片仍是冻结屏幕的裁剪，窗口被遮挡的部分不会额外捕获。
- **调整大小**：将鼠标移到选区四角或四边的手柄上，拖动调整边界。
- **移动亮区**：使用“选择”工具，在亮区空白位置按住拖动；抓住已有标注时则移动该标注。
- **重新框选**：从暗区开始拖动可重新选区。标注保留在原始画面位置，输出按最终选区裁剪。
- **标注工具**：画笔、矩形、椭圆、箭头、文字、马赛克、序号，支持五色色板、撤销和重做。
- **Esc**：先取消正在输入的文字或拖拽，再次按下可取消整个截图。

## 截图输出

- **勾选 / 复制**：将带标注的选区复制到系统剪贴板并结束截图。不会自动添加到 AI 会话；需要时在聊天、文档或其他应用中粘贴。
- **保存**：打开保存对话框，选择路径后保存为 PNG。保存或取消路径选择后仍可继续编辑。
- **图钉**：将当前选区钉在桌面，结束截图。钉图窗口始终置顶，可拖动位置，单击图片关闭；关闭时清理临时图片。

## 平台说明

- **Windows 桌面版**：已有本机验证包，支持多屏和悬停选窗。
- **macOS 桌面版**：本分支新增 helper 原生多屏捕获、窗口候选和 Retina 坐标适配，尚需 Mac 原生构建与实机验收。macOS 14+ 使用 ScreenCaptureKit，较旧系统使用 CoreGraphics 兼容路径。
- macOS 首次使用若提示缺少权限，点击“去授权”，在系统设置的屏幕录制权限中允许 `codeg-computer-helper`，然后重新发起截图。无需开启 Computer Use，也不下载 agent 驱动。
- Linux 截图暂不支持；Web 和远程工作区不显示截图入口。
- 本机安装包用于本地验证，不代表已发布新版本。Mac 构建与验收步骤见 `docs/screenshot-macos-validation.md`。
