# YoYoCode v0.45.0-plus.6

会话待发队列、会话列表与语音输入的体验升级：报错后队列按意图自动放行、待发消息 +1 折叠计数、会话列表一键「在新会话中继续」、收缩侧栏悬停浮出，以及语音模型下载进度常驻状态栏。

## 待发队列

- 报错（非用户主动停止）结算时，若队首消息本身就是一条「继续」指令（10 种语言判定，覆盖桌面端「继续未完成任务」按钮的固定话术），队列自动放行继续排空 —— 发出的是用户排队的原话；否则维持暂停等待用户处理。用户停止的 hold、恢复轮取消的暂停语义不变。
- 待发消息支持 +1：为「继续」类消息再排一份相同拷贝；相同消息自动折叠为「继续 xN」，每发出一份 N−1。折叠为展示层行为，删除/编辑/立即发送各只作用于一份拷贝；拖拽排序按折叠组进行。

## 会话列表

- 右键菜单新增「在新会话中继续」：仍在运行的会话先确认「停止并继续」（停止旧会话并标记完成），新建会话自动预填 @老会话 引用，不自动发送。委派子会话不提供该项。

## 左侧栏

- 收缩态悬停左上角按钮区即可浮出完整侧栏（覆盖内容区，不挤压布局），移开或 Esc 自动收回；点击按钮仍为正式展开。
- 最小拖拽宽度 224px → 192px（macOS 桌面 300px → 268px）。

## 语音输入

- 模型下载/安装进度常驻状态栏（百分比、提取阶段），不再使用遮挡聊天的 loading toast；离开输入框也能看到进度。失败与就绪提示保留。

## 升级说明

- 构建产物及更新清单使用 `0.45.0-plus.6`；已安装 `0.45.0-plus.5` 的用户在本版正式发布后可使用内置更新。
- 仓库上游版本基线仍为 `0.45.0`，PLUS 版本号、品牌和更新源由构建期注入。
- 服务器包提供 Linux x64、Linux arm64、Windows x64。
