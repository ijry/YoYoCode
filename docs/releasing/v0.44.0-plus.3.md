# YoYoCode v0.44.0-plus.3

## 本版范围

基于上游 Codeg 0.44.0 的第三个 PLUS 迭代，包含自 `v0.44.0-plus.2` 以来的 10 个提交。沿用 safe 身份模式：安装包内部应用版本仍为 `0.44.0`，Plus 迭代号由 tag / Release 标题承载。

## 关于页与品牌

- **「关于」页链接分层**：拆成「本仓库 / App 端连接 / 上游 Codeg」三张卡片。本仓库提供仓库、版本发布、问题反馈与文档入口；App 端提供 MCode 下载与 Web 服务设置快捷入口；上游分组只保留 `spacering-net/codeg` 仓库链接与致谢。十种语言文案同步。
- **动态 Lottie 水母徽标**：顶部静态图标换成 `AboutLogoAnimation`，按需加载 `public/logo/animation/` 下的 vendored `lottie-web` 与 `jellyfish-breathe.json`，尊重系统「减少动画」偏好，加载失败降级到透明静帧。runtime 由 `scripts/` 移到 `public/logo/animation/`，页面与生成脚本共用一份，不进应用 bundle。

- 本仓库 14 文件 / 415 处 `docs.codeg.app` 链接统一替换为自有 Pages 地址（含 10 个 README 徽章），路径与锚点原样保留；Rust 侧 ACP 文档链接、上传上限注释与测试夹具同步。

## server 二进制与 Release 资产全量改名

- `codeg-server` 统一为 `yoyocode-server`：Cargo `[[bin]]` 名、源文件 `yoyocode_server.rs`、压缩包内可执行文件名、安装目录与 PATH 命令名、Docker、更新器查找名、十语言文案、文档与测试夹具全部同步；`cargo metadata` 已确认新 bin target。
- **Release 资产只发一套**：`release.yml` 删除 `legacy_artifact` 与双份复制 / 签名 / 上传循环，每个平台只产 `yoyocode-server-*`；`install.sh` / `install.ps1` 删除「新名 404 回退旧名」逻辑。本版资产列表中不再出现 `codeg-server-*`。
- 保留 `CODEG_*` 环境变量、`CODEG_STATIC_DIR`、`.codeg` 数据目录、`codeg://` URL scheme 与桌面端安装包名前缀等协议兼容标识。

## 使用说明

- 默认端口仍是 **18989**；MCode 连接配置码包含访问令牌，请勿分享。移动端统一从 `getmcode.lingyun.net` 获取，文档在 `https://ijry.github.io/yoyocode-docs/`。
- **重要：从 plus.1 / plus.2 升级请手动重装。** 这两个版本内置的更新器会在下载包内查找旧名 `codeg-server`，而本版包内只有 `yoyocode-server`，直接点「软件更新」会失败。请从本版 Release 手动下载桌面安装包或 server 压缩包覆盖安装；本版之后的内置更新恢复正常。
- Server 命令名由 `codeg-server` 改为 `yoyocode-server`；脚本、systemd unit、Docker Compose 与 PATH 中若写死了旧命令，需要同步修改。
- macOS 安装包沿用 ad-hoc 签名，不做 Apple 公证。
