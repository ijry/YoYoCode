# YoYoCode v0.45.0-plus.1

## 本版范围

合并上游 Codeg **v0.45.0** 后的首个 PLUS 迭代，基线从 `0.44.0` 升到 `0.45.0`。包含上游 `v0.45.0` 的全部改动，以及本 fork 自 `v0.44.0-plus.5` 以来的合并工作。版本号随上游更新为 `0.45.0`，迭代号由构建期身份注入写成 `0.45.0-plus.1`（semver 模式，沿用 plus.5 起的版本机制）。

## 合并上游 0.45.0

- **上游基线**：`spacering-net/codeg` 主线 `4991406e6`（含 release tag `v0.45.0` = `bd88b9dac` 及其后 4 个 tasks 修复）。合并前本 fork 相对上游 99 个自有提交 / 上游 30 个提交。
- **上游带入的新能力**：acp 消息边界保留、Claude prompt-cache 模式开关与多个 CLI/IDE 集成版本升级、work-task 后台保持（holds）机制、config-sync 快照保护、config appearance 同步、tasks 时间过滤器等。
- **冲突融合（保留双方改动）**：
  - `work_task/engine.rs`：上游新增 `holds` 后台保持机制，本 fork 的 `manager.cancel` 为三参数 `by_user`（消息队列扣留功能）；融合为保留 holds 逻辑 + cancel 传 `false`。
  - `status-bar.tsx`：采用上游 service indicators 新顺序（Mcp→WebService），保留本 fork 的 `yoyocode-mcp` 品牌注释。
- **功能完整性核查**：逐行扫描 fork 引入的 55,411 行代码，除上述一处注释改写外全部存活；fork 独有 178 个新增文件字节级一致；消息队列、定时发送、Tailscale/Funnel、截图工具、漫画工作台、ZCode 供应商、CLI/MCP/server 重命名等核心符号全部保留。

## 升级路径

- **本次跨上游 minor 版本（0.44→0.45），core version 变大**：按 semver，`0.45.0-plus.1` 高于所有存量版本——包括已装 semver 版的 `0.44.0-plus.5`，以及更早只装到纯三段 `0.44.0` 的用户（plus.1~plus.4）。**所有存量用户都能收到自动更新提示**，这是 plus.5 之前纯三段用户断裂问题的自然修复。
- 沿用既有约定：默认端口 **18989**；MCode 连接配置码包含访问令牌，请勿分享；macOS 安装包为 ad-hoc 签名，不做 Apple 公证。
- server 侧：从 `0.44.0-plus.5`（已用 `yoyocode-server` 新名）升级无改名断裂；更早的 plus.1/plus.2 用户若仍内置查找旧名 `codeg-server`，需手动重装，此为历史限制。

## 验证

- 后端：`cargo check` 桌面模式与 server 模式（`--no-default-features --features server-bin --bin yoyocode-server`）双通过，含手改的 `work_task/engine.rs`。
- 前端：vitest 失败用例低并发（`--maxWorkers=1`）重跑 19/19 通过；全并发下的超时为环境资源争抢导致的 flaky，非回归。
- 发版脚本：`node --test scripts/server-release.test.mjs scripts/server-install-download.test.mjs` 14/14 通过；身份注入 `--check` 确认 `0.45.0 → 0.45.0-plus.1`，updater 端点指向 `ijry/YoYoCode`。
- tag `v0.45.0-plus.1` 通过 CI 校验正则（`^v0.45.0-plus\.[0-9]+$`）；含 `-` 触发 RPM 跳过逻辑。

## 已知限制

- macOS 仍为 ad-hoc 签名，无 Developer ID 公证。
- 桌面 installer 生成与 updater 签名以 CI 实际结果为准（跨 minor 版本的 semver prerelease 打包沿用 plus.5 起的机制）。
