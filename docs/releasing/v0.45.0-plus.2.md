# YoYoCode v0.45.0-plus.2

修复暂停队列阻塞用户继续会话的问题，并改进队列恢复、ZCode 供应商切换及侧边栏会话列表体验。

## 消息队列与会话恢复

- **暂停不再阻止手动发送**：上一任务错误中断后，在输入框发送的新消息立即提交给当前会话，不再排到只能通过提示按钮解锁的队列后面。
- **按消息恢复会话**：暂停时，每条待发送消息提供「发送此消息并继续会话」按钮，可选择任意一条作为下一轮输入；其他消息继续留队，当前轮成功完成后才恢复自动发送。
- **中断提示可关闭**：提示右上角提供关闭按钮，仅隐藏提示，不会自动发送队列内容；出现新的失败时重新提示，关闭后各条消息的发送按钮仍可用。
- **保留发送安全边界**：自动队列仍遵守暂停规则；已经请求恢复或正在运行的回合不会被第二条消息打断；失败或交付结果不确定的消息继续使用带重复发送确认的重试流程。
- 同步修复后端发送前置检查与原子受理检查的语义，确保输入框直发和手动选择的队列消息可以通过暂停，而自动发送不会自行解除暂停。

## ZCode 供应商快捷切换

- 输入框的模型/设置弹窗新增 ZCode 供应商选项，与模型、推理及模式设置集中展示，无需进入智能体设置页。
- 支持选择「自动」以交由桥接器扫描供应商；供应商属于启动级配置，切换后通过重新连接应用，不强行中断正在进行的回合。

## 会话列表展开与收起

- 文件夹、置顶、最近及聊天列表统一默认显示五条，「查看更多」每次增加五条，各列表独立控制，也可收起回首屏。
- 兼容文件夹分组与工作树层级；定位当前会话时自动展开到目标所在页，收起后保留键盘焦点。
- 新增交互与提示覆盖十种界面语言。

## 升级说明

- 延续完整版本号机制，构建产物及更新清单使用 `0.45.0-plus.2`，已安装 `0.45.0-plus.1` 的用户在本版正式发布后可使用内置更新。
- 仓库内上游版本基线仍为 `0.45.0`，PLUS 版本号、品牌和更新源由构建时注入，无新增数据库迁移。
- 默认 Web 服务端口仍为 **18989**；MCode 连接配置码包含访问令牌，请勿公开分享。
- macOS 安装包仍采用 ad-hoc 签名，尚无 Apple Developer ID 公证；服务器包继续提供 Linux x64、Linux arm64、Windows x64。
