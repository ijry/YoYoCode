# YoYoCode v0.48.1-plus.1

首个基于上游 Codeg **0.48.1** 的 PLUS 迭代。合并了上游 0.46.0 / 0.47.0 / 0.48.0 / 0.48.1 的全部改动，并带上 fork 自有的功能与修复。自 `v0.45.0-plus.9` 以来的主要变化如下。

## 上游基线升级（0.46.0 → 0.48.1）

- **SRN 账号登录与「驾驭工程」页面**：状态栏左侧新增 SRN（SpaceRing）账号入口；工作区侧边栏新增「驾驭工程」页，集中管理各智能体的 MCP 服务器与技能，MCP / 技能 / 技能包入口从「设置」迁入该页。
- **Harness 插件一键安装**：在「发现」中把 superpowers 等插件装到 Claude Code / Codex / OpenCode，按智能体分别选择插件、纯技能或不装，并支持更新、修复、卸载与模式切换。
- **每个会话独立保存模型、思考强度与模式**；待办任务沿用创建时的智能体与设置，并在原会话中重跑。
- **侧边栏「最近」按时间分组**（进行中 / 今天 / 昨天 / 前 7 天 / 前 30 天 / 更早），标题栏可切回平铺列表，选择会被记住。
- **智能体更新**：Claude Code 0.110.1、Codex 2.10.0、OpenCode 2.4.1、Kimi Code 2.7.3、DeepSeek 0.12.0，以及 Cline / Grok / Hermes / Cursor / Antigravity / ZCode / Command Code / pi 等；Codex 新增 GPT-6.2，DeepSeek 支持在设置页配置 pi-ai 供应商路由。
- 待办任务、Antigravity 失败显示、Markdown 本地图片、网络挂载目录卡死、Windows 崩溃与多处内存泄漏等修复。详见上游 0.46.0 / 0.47.0 / 0.48.0 / 0.48.1 发布说明。

## PLUS 自有改动

- **深链协议迁移到 `yoyocode://`**：OS 层不再注册 `codeg://`，避免与官方版抢同一个 scheme；新写入统一使用 `yoyocode://`，存量数据库、磁盘会话文件、旧草稿与 LLM 上下文中的 `codeg://` 仍可解析、渲染与路由。外部脚本 / 浏览器里旧的 `codeg://` 深链不再唤起本 app。
- **MCP 阻塞工具声明 `_meta.timeoutMs`**，不再被宿主 MCP 默认 30s 超时杀掉。
- **队列与交互修复**：手动停止横幅在新回合运行时自动隐藏，并支持手动关闭；会话标记为完成后自动关闭对应标签页；预览标签标题恢复斜体。
- **品牌图标**：全平台换为新蓝色水母 + iOS squircle 圆角；斜置水母 logo 缩小至 90%（含菜单栏 tray）。
- **CI**：macOS 发布拆成 arm64 / x64 两个并行 job，缩短构建时间；Test 工作流 macOS 只跑桌面 Rust 单元。

## 升级说明

- 构建产物与更新清单使用 `0.48.1-plus.1`（semver 模式），更新器可从 `0.45.0-plus.9` 正常识别到本版。
- 仓库上游版本基线仍为 `0.48.1`；PLUS 版本号、品牌与更新源由构建期注入，git 历史中的身份字段与上游逐位相同。
- macOS 安装包沿用 ad-hoc 签名，不做 Apple 公证；server 不发布 macOS 版，Mac 用户使用桌面版即可。
- 服务端默认端口仍为 **18989**；MCode 连接配置码包含访问令牌，请勿分享。

## 验证

- 以 Release workflow 各构建门禁为准：桌面六平台（macOS arm64/x64、Linux arm64/x64、Windows arm64/x64）、三平台 server、Docker 镜像、更新清单与资产签名校验。
- 上游 0.46.0 / 0.47.0 / 0.48.0 / 0.48.1 的更新说明随合并带入；本版未重新执行全量本地测试，以 CI 结果为准。
