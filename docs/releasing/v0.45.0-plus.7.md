# YoYoCode v0.45.0-plus.7

修复 ZCode 计划余量摘要的两个问题。

## 余量摘要修复

- 一次瞬态失败（回合进行中打开模型弹窗导致的 8 秒超时）曾把该连接永久标记为「不支持 account/usage_stats」，此后余量摘要永远不再尝试显示。现在只有适配器明确回答「未知方法」（JSON-RPC -32601 / Method not found）才钉终身裁决；超时等瞬态失败在下次打开弹窗时自动重试。

## 模型胶囊修正

- 模型胶囊不再同时出现两个供应商名：供应商行不再向胶囊摘要贡献文字 —— 模型行的摘要已命名运行中的「套餐 › 模型」（例如 Start Plan › GLM-5.3-Flash），供应商行的 `current_provider_id` 可能落后于模型切换，两处连排读成显示错误。供应商选择器保持弹窗内全部功能与高亮不变。

## 升级说明

- 构建产物及更新清单使用 `0.45.0-plus.7`；已安装 `0.45.0-plus.6` 的用户在本版正式发布后可使用内置更新。
- 注意：plus.6 的余量摘要问题只需重开应用/重连会话即可临时恢复显示（裁决仅存于会话内存）；本版从机制上修复。
- 仓库上游版本基线仍为 `0.45.0`，PLUS 版本号、品牌和更新源由构建期注入。

## 验证

- 账号用量 Rust 测试 **7/7**（归一化、TTL、临时失败判定表）通过；clippy（server-bin 模式）`-D warnings` 通过。
- 会话设置测试 **23/23**（供应商行不再上胶囊、弹窗标签与高亮不变）通过。
- ESLint、TypeScript 全量检查通过；静态构建与服务器发布脚本测试（25/25）通过。
