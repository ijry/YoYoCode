# YoYoCode v0.49.0-plus.1

基于 Codeg 0.49.0，合并上游至 `20e5e2774`（含发布后的修复，共 226 个提交），并保留 YoYoCode 的本地增强。

## 本次变化

- **同步上游 0.49.0**：引入个人助手、新版会话详情、消息回退编辑、选中文本询问侧栏，以及子任务停止、助手草稿保存等后续修复。
- **消息队列**：包含上一版发布后的排序恢复和手动暂停；保留后端自动发送、定时发送、错误恢复、停止扣留及 `+1`。新消息回退流程与队列发送门槛共同生效。
- **漫剧工作台**：任务继续送入当前会话，沿用当前上下文和消息队列；交接模块整理为 `workbench-task-handoff`，同步补齐快捷菜单入口与关闭标签清理。
- **兼容改名后的工具与链接**：新助手支持 `yoyocode://bot/` 与旧 `codeg://bot/`；MCP 审批及保留名称同时识别 `yoyocode-mcp` 和旧名称。上游 77 个工具与本地 31 个漫剧工具均保留。
- **保留已有增强**：轮次上限三态续跑、模型切换记录、ZCode 供应商与配额摘要、语音输入、截图、侧栏悬停展开、Tailscale/MCode 接入及 YoYoCode 品牌配置。
- **最近会话列表**：采用上游时间分组与每次 10 条分页；其他列表继续使用本地每次 5 条的展开方式。
- **发布预检**：修正过期的 macOS 单任务双架构测试，匹配现有两个 Intel runner 并行构建的流水线，保留两种架构的 sidecar 与 bundle 校验。

## 升级说明

- 构建产物与更新清单使用 `0.49.0-plus.1`；仓库版本字段仍为上游基线 `0.49.0`，PLUS 版本号、品牌和更新源在构建时注入。
- 桌面与 server 升级通道保持独立；server 默认端口为 **18989**。
- macOS 安装包沿用 ad-hoc 签名；安装方式与上一版相同。
