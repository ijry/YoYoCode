# YoYoCode v0.42.0-plus.4

基于 Codeg 0.42.0，汇总 v0.42.0-plus.3 之后的改进。

## 新增与改进

- **Tailscale 固定公网访问**：设置 → Web 服务新增 Tailscale Funnel，安装后可一键衔接 Web 服务启动、Tailscale 连接/登录和公网授权。成功后优先显示 HTTPS 地址，手机浏览器无需安装 Tailscale。
- **MCode 配置二维码**：移动端远程管理区域显示连接配置二维码，随当前所选地址更新，可扫码或复制配置码导入 MCode。配置码包含访问令牌，请勿分享。
- **配置流程提示**：区分设备审批、DNS、系统服务和端口配置冲突；支持取消、失败后重试及已授权配置恢复。
- **截图体验**：就地标注工具条、选区移动与缩放、悬停识别窗口、桌面钉图、另存为和剪贴板复制；新增 macOS helper 捕获通道及多屏/Retina 适配。
- **会话模型切换**：持久化并显示会话内模型切换。
- **漫画工作台**：完善创作工作流与相关界面操作。
- **桌面品牌**：窗口标题及托盘显示统一为 YoYoCode。

## 使用说明

- Tailscale 需安装在运行 YoYoCode 的主机，首次账号登录、公网授权仍需用户确认。入口地址在保留节点身份及 DNS 名称时稳定；不承诺永久在线。
- 公网入口继续要求 Codeg 访问令牌。不要将 MCode 配置码与普通网页二维码混淆。
- 请避免使用其他工具同时修改 Codeg 所管理的 Tailscale 443 映射。
- 使用步骤：[Tailscale 与 MCode 连接](../tailscale-funnel.md)。
