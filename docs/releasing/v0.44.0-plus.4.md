# YoYoCode v0.44.0-plus.4

## 本版范围

基于上游 Codeg 0.44.0 的第四个 PLUS 迭代，包含自 `v0.44.0-plus.3` 以来的 3 个提交。沿用 safe 身份模式：安装包内部应用版本仍为 `0.44.0`，Plus 迭代号由 tag / Release 标题承载。

## ZCode 智能体支持供应商切换

- **设置 → 智能体 → ZCode 新增「供应商」下拉**：列出 ZCode 桥接器（zcode-acp-server）可固定的供应商账号并写入 `ZCODE_PROVIDER`。此前 ACP 通道只有扁平模型列表，ZCode 的供应商（账号套餐 / 自定义端点）在 YoYoCode 里不可选——本版把供应商维度补齐到设置层。
- 供应商列表由后端镜像上游桥接的扫描规则生成（`~/.zcode/v2/config.json` 供应商表 + `zcode-acp setup` 保存的 `acp-accounts.json` 叠加 + `providerSelectable` 可用性判定），只含 id / 名称 / 可用性，永不携带 API 密钥；文件缺失或损坏时降级为空列表并保留「自动」项。
- 「自动」保持桥接器自身语义（首个已启用供应商）；手输的自定义 id 原样透传；未启用或缺少凭据的供应商在下拉中带提示，显式选择仍会被上游尊重。
- 修复 `agent_env_keys` 的 ZCode 兜底：占位符特意避开 `ZCODE_BASE_URL`（该变量是 app-server 的 service origin，桥接器会剥离任何继承值），模型槽用真实的 `ZCODE_MODEL`；ZCode 加入 `keeps_own_providers`，绑定模型供应商会被明确拒绝而不是静默写无效变量。

## 使用说明

- `ZCODE_PROVIDER` 是启动级变量：下拉选择并保存后，对**下一次连接**的新会话生效，进行中的会话不受影响。
- 登录账号的套餐模型（如 Start Plan）暂不在下拉中：上游桥接在 headless 下依赖 config.json 的供应商条目，而账号套餐条目是 disabled/keyless。已向上游提 issue（william0wang/zcode-acp#400）请求会话级供应商切换与账号套餐可见性；此前切换供应商的替代做法是先在 ZCode app 内切换连接。
- 其余沿用 plus.3 说明：默认端口 **18989**；MCode 连接配置码包含访问令牌，请勿分享；macOS 安装包沿用 ad-hoc 签名，不做 Apple 公证。
- 升级路径：plus.3 → plus.4 内置更新正常；plus.1 / plus.2 仍需手动重装（server 改名断点已在 plus.3 修复）。
