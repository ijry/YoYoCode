# YoYoCode v0.45.0-plus.4

修复 macOS 27 上点击输入框麦克风后立即提示「语音输入失败」的问题：macOS 桌面端改走本地识别链路，并补齐麦克风用途说明及主程序的录音授权。

## macOS 语音输入修复

- macOS Tauri 桌面端不再选择 WKWebView 暴露但语音服务不可用的 Web Speech，默认使用本地 PCM 采集和 sherpa-onnx / whisper 识别。
- Windows Tauri 与普通浏览器仍保留原有浏览器语音选择行为。
- 麦克风权限拒绝现在显示明确提示；本地录音启动失败会清理录音器和流式识别会话，避免残留状态妨碍重试。
- macOS app bundle 新增 `NSMicrophoneUsageDescription`；Hardened Runtime 下为主程序授予 Audio Input entitlement。
- 命令行 sidecar 单独 ad-hoc/runtime 签名后放回原有 sibling 路径，不继承麦克风 entitlement；电脑操作 helper 仍位于 `Contents/Helpers`，不取得麦克风授权。
- macOS Release CI 检查最终 app 的用途说明及主程序 entitlement，并保持 sidecar/helper 无多余 entitlement 的签名限制。

## 其他功能

- 延续 plus.3 的本地双引擎语音输入、中英流式识别与其他语言 whisper 批式回退，以及 ZCode 会话内供应商切换。

## 升级说明

- 构建产物及更新清单使用 `0.45.0-plus.4`；已安装 `0.45.0-plus.3` 的用户在本版正式发布后可使用内置更新。
- 仓库上游版本基线仍为 `0.45.0`，PLUS 版本号、品牌和更新源由构建期注入。
- macOS 安装包仍使用 ad-hoc 签名，未做 Apple Developer ID 公证；服务器包提供 Linux x64、Linux arm64、Windows x64。
