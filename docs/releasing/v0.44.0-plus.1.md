# YoYoCode v0.44.0-plus.1

基于 Codeg 0.44.0，汇总 v0.42.0-plus.4 之后的上游合并与本仓库自有改动。

## 上游基线：Codeg 0.44.0

本版把上游从 0.42.0 合并到 0.44.0（含 0.43.0），主要带来：

- **对话流式性能**：长回复与流式输出的渲染明显加快，长回复时间轴在滚动时保持绘制且不再抖动。
- **搜索索引**：打开的工作区文件索引由文件事件保持最新，键盘连续输入与 `Cmd+K` 结果保持新鲜；事件维护的快照有界，避免看不到的变更累积。
- **内存与缓存**：HTML 预览文档与偏好改为有界保留；取消的桌面补水任务立即释放，取消的快照等待正常收敛。
- **Forge（PR/MR）**：列表显示 CI 检查状态与检查数量，可批准被扣住的 GitHub workflow；支持发布经 agent 复核的线程回复，并补上 GitLab 对象存储图片与磁盘缓存图片的加载。
- **任务**：交付 PR 时一并提交工作树里的遗留改动；对话可从悬停子菜单移入文件夹，并支持移动到其他项目。
- **Web 服务**：状态栏新增可达性指示与开关，绑定地址可选仅回环。
- **ACP 适配器**：CodeBuddy 2.184.0、Kimi Code 2.6.1、Qoder 1.1.88、Antigravity 1.5.0、Cursor 2026.11.11-b912975、ZCode 0.84.2；修正 ACP elicitation 的问题文本与选项描述丢失。
- **活动时间轴**：命令行步骤使用终端图标，codex 协作子智能体操作绘制为时间轴行；回合后仍在运行的任务显示为「N running」。

## 新增与改进（本仓库自有）

- **全新应用图标**：替换为章鱼图标，覆盖桌面安装包（含 Windows `.ico`、macOS `.icns` 的 824/1024 安全区）、PWA 图标（含 maskable 变体）与 favicon。图形由源图逐像素追踪并经最小二乘拟合配色，与原图轮廓一致度 0.993、颜色平均误差低于 1/255。
- **Web 服务默认端口改为 18989**：Docker、`docker-compose`、安装脚本、`codeg-server`、CLI 与各语言文档统一从 3080/18080 迁到 18989，避免与常见开发端口冲突。
- **MCode 连接命名**：连接配置码携带宿主机的操作系统主机名，多台机器在手机端 MCode 列表中可区分。
- **手动停止后扣住消息队列**：手动停止回合时自动发送暂停，队列保持不动；可在队列横幅点「恢复自动发送」，或对单条消息点「立即发送」。此时输入框发送的消息直接进入会话，不再排队。下一个回合正常完成后队列自动恢复。自动取消（自动化、工作任务、CLI 运行）不影响队列。
- **定时发送入口合并**：定时发送并入发送按钮右侧的下拉菜单（右侧分体部分默认隐藏、悬停时浮现，触屏设备常显），不再单独占用一个图标。无实时反馈通道的回合也会显示排队发送按钮，此前只能靠回车。
- **实时反馈默认开启**：`feedback.enabled` 改为默认开启，与「向用户提问」一致；不需要时可在设置中关闭。
- **交互细节**：「上一任务因错误中断」横幅在续跑回合真正开始后消失；定时发送弹窗改用轻遮罩，背景会话保持可读。
- **漫画工作台**：修正原子化字段更新与待发草稿、已确认媒体的保留，支持仅视频合成，并在提交前预检本地媒体工具。

## 使用说明

- Docker / `codeg-server` 的默认端口已改为 **18989**，升级后请同步调整反向代理、防火墙、Tailscale Funnel 映射与书签；仍可用 `CODEG_PORT` 指定其他端口。
- MCode 连接配置码包含访问令牌，请勿分享。
- 实时反馈默认开启：支持即时插入的智能体会在当前回合直接看到备注，其他智能体通过检查反馈的工具读取，通常需要在提示词里提醒它定期检查。

## 验证与已知限制

- 前端生产构建（静态导出）通过；桌面 / 服务器 / MCP 三种 Cargo 目标编译检查通过；`tsc --noEmit` 无错误。
- 合并上游 0.44.0 时手工解决了 24 个文件的冲突（i18n 键、Rust 结构字段、Web 服务绑定地址与端口、设置页状态机等），相关前端测试通过。
- 全量前端测试仍有既有失败：任务页 mock 加载、CRLF 源码匹配断言，以及并行负载下的偶发超时；隔离重跑均通过。Rust 全库测试在部分开发机上因环境问题无法加载测试二进制，需以 CI 结果为准。这不代表整仓检查全绿。
- macOS 安装包沿用 ad-hoc 签名，不做 Apple 公证。
- 本版沿用 safe 身份模式：安装包内部应用版本为 `0.44.0`，Plus 迭代号由 Release/tag 区分。若应用内更新未提示，可从本版 Release 下载并手动升级。
