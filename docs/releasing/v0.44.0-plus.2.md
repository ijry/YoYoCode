# YoYoCode v0.44.0-plus.2

## 本版范围

基于上游 Codeg 0.44.0 的第二个 PLUS 迭代，包含自 `v0.44.0-plus.1` 以来的 17 个提交。沿用 safe 身份模式：安装包内部应用版本仍为 `0.44.0`，Plus 迭代号由 tag / Release 标题承载。

## 品牌与图标

- **命令行改名收尾**：设置页「命令行访问」示例与十种语言文案统一为 `yoyo-cli`；Dockerfile、Windows NSIS 安装钩子、CI clippy 目标与桌面打包测试同步到 `yoyo-cli` / `yoyocode-mcp`。协议兼容项（握手域串 `codeg-cli-hello`、环境变量 `CODEG_CLI`）保留；历史会话中的旧 MCP server 名仍可识别。
- **macOS 菜单栏图标**：`tray-icon-template.png` 此前仍是上游括号/圆点 mark，现由 `tray-icon-template.gen.py` 从 `icon.svg` 派生水母单色 template（黑色 RGB + alpha，由系统按菜单栏明暗染色）。
- **Dock 图标排查与防回归**：确认 `icon.icns` 在源码、`be3004562` 与已发 tag 三处逐字节一致；升级后 Dock 仍是旧图标属 macOS IconServices 缓存或旧 Dock 项。`release.yml` 新增校验：把成品 `.app` 内 `Contents/Resources/*.icns` 与仓库图标逐字节比对，不一致直接失败。
- **高清 logo 与呼吸动画**：新增 `public/logo/v1/` 水母矢量重绘（512/1024/2048/4096 PNG、1024 白版与预览页）；新增 `public/logo/animation/` 两套透明动画——36 帧 RGBA animated WebP 与 25fps Lottie/Bodymovin，附透明静帧与自包含离线预览。生成脚本归入 `scripts/` 并改为基于 `__file__` 的相对路径，两次重跑产物逐字节一致。

## 功能与修复

- **状态栏 Web service 小窗**：补充 Tailscale Funnel 状态速览、公网 HTTPS 地址复制、直达设置入口，以及 MCode 手机扫码 / 复制配置码 / 下载 App；二维码弹窗置于 Popover 外层避免层级冲突，十种语言各补 15 条文案，单文件测试 18/18 通过。
- **消息队列**：切换会话前清空旧 owner 的权威队列，避免 parked-draft hydration 把旧队列写进错误会话，新增回归测试。
- **输入交互**：空草稿时隐藏回合中的发送类按钮。
- **Rust 与前端清理**：漫画工作台拆出原子写入辅助函数并整理 provider；并发计数改 `compare_exchange_weak`；clippy 告警清理；前端测试适配 CRLF 源码断言与任务页 mock；`.zcode/plans/` 计划文档纳入版本控制，其余临时产物忽略。

## 使用说明

- 默认端口仍是 **18989**；MCode 连接配置码包含访问令牌，请勿分享。
- **升级后 macOS Dock 仍是旧图标**：包内图标已是水母，先按 `docs/releasing/v0.44.0-plus.1.md` 的梯度刷新 Dock / IconServices 缓存；若 Dock 项指向改名前的 `codeg.app`，移除后重新拖入 `YoYoCode.app`。
- 仓库新增的 Lottie 数据需在应用侧自行安装 `lottie-web` 才能播放；项目当前未引入该依赖，附带的预览页已内联运行时，仅供离线查看。

## 验证与已知限制

- 状态栏小窗单文件测试 18/18、`tsc --noEmit`、十语言 key parity、`git diff --check` 通过。
- 透明 WebP 的 `VP8X` / `ANIM` / 逐帧 `ALPH` 结构、Lottie 首尾形状闭合与浏览器三底对照均已验证；发版图标校验用正确 / 过期两份 fixture 实测分别放行与拦截。
- 本轮未重新执行全量前端生产构建与 Rust 全库测试，以 CI 结果为准。仓库既有基线：全量 Vitest 在并行负载下有偶发超时、CRLF 相关 ESLint `Delete ␍` 报错，隔离重跑通过，不代表整仓检查全绿。
- macOS 安装包沿用 ad-hoc 签名，不做 Apple 公证。
- 应用内更新未提示时，可从本版 Release 手动下载安装。
