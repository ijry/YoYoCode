## MCode 配置码连接名称改为系统机器名

需求：设置页生成的 MCode 配置码里 `name` 写死 `"Codeg"`，希望改成主机名称以区分多台机器。
用户选择「系统机器名优先，取不到时回退」。

实现（6 个文件，+200/-11）：
- `src-tauri/src/web/mod.rs`：`WebServerInfo` 新增 `host_name: Option<String>`（serde → `hostName`）；
  新增 `machine_host_name()`（OnceLock 缓存）+ `usable_host_name()` 清洗 +
  `platform_host_name()` 跨平台：Windows 读 `COMPUTERNAME`/`HOSTNAME`，Unix 用 `libc::gethostname`
  （libc 0.2 的 unix 签名是 `len: size_t`，已在 registry 源码核实），其他平台返回 None。
  三处 `WebServerInfo` 构造点全部补齐；加了 2 个单测。
- `src/lib/api.ts`：镜像类型加可选 `hostName?: string | null`（兼容旧后端）。
- `src/lib/mcode-config-code.ts`：`buildMcodeConfigCode(address, token, hostName?)`，
  回退链 = 系统机器名 → 地址 hostname（IPv6 去方括号）→ `"Codeg"`；
  名称 trim、限长 64、拒控制字符。
- `src/components/settings/web-service-settings.tsx`：调用处传 `status.hostName`。
- 两个测试文件同步更新并补充机器名/回退用例。

## 本仓库验证要点（重要基线）
- 仓库工作区文件是 **CRLF**，`.prettierrc` 未设 `endOfLine`（默认 lf），
  所以直接 `eslint <file>` 会对每一行报 `Delete ␍`（全项目基线，未改动文件同样如此）。
  判断真实 lint 问题要过滤掉 `Delete ␍`；用 prettier API 把内容转 LF 格式化后再转回 CRLF 写回。
- `tsc --noEmit -p tsconfig.json` 有 8 个既有错误：`getByRole` 的 `exact` 不属于
  `ByRoleOptions`（都在 web-service-settings.test.tsx 原有代码里）。
- 全量 `vitest run`：11699/11711 通过；12 个失败均是既有问题（tasks-page.search/focus 模块加载、
  custom-skills-settings 超时/pointer-events、activity-rows 超时、
  use-transcript-known-invocations 源码文本断言），单独复跑仍失败，与改动无关。
- Rust `cargo check`（桌面默认 + `server-bin`）两种模式都通过。
- **Rust 单元测试二进制在本机跑不起来**：编译成功但启动即 `0xc0000139 STATUS_ENTRYPOINT_NOT_FOUND`，
  用既有测试过滤器、改用 PowerShell 运行同样崩溃 → 环境级 native DLL 问题，非代码问题。
  验证 Rust 改动只能靠 cargo check + 静态复核。
