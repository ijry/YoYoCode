## 修复 Lottie 高光缺失与预览白闪（11:55）

用户「是不是缺失了一个左上角的高光，另外怎么屏幕会闪白一下」。

- 根因（高光）：`icon.svg` 注释写明高光是 "in the tile colour, so it reads as a cut-out"，
  即原品牌图标靠**白色地砖**透出来形成高光。深色/透明动画没有白地砖，之前照搬
  「挖空」语义：GIF/WebP 用 `soft_mask(bell, sheen)`，Lottie 用 `masksProperties.mode="s"`
  subtract mask，结果左上角变成暗洞/纯蓝平涂，白色高光消失。
- 修法：GIF/WebP 改 `soft_mask(bell)`，在 bloom 之后叠加真实白色高光（core 0.96 +
  淡青 aura 0.24，均裁剪在伞盖内）；Lottie 删掉 subtract mask，新增最上层
  "Specular highlight" 图层（白色 fill 96% + 淡青 halo stroke），路径仍由
  `highlight_shape` 关键帧驱动，随呼吸伸缩。图层由 3 变 4，首尾形状仍逐点相同。
- 根因（白闪）：预览页 `<html>` 背景透明、无 `color-scheme` meta，宿主 webview 在
  CSS 首帧前先画默认白底；且 lottie-web 的 subtract mask 会在 `<defs>` 里放一个
  480×480 `#ffffff` 矩形，循环缝上也有白闪观感。
- 修法：head 最早处加 `<meta name="color-scheme" content="dark">` + `theme-color`，
  `<html>`/`<body>` 内联 `#0b1220`，CSS 补 `html,body{background:#0b1220}`；
  `#lottie` 初始 `opacity:0`，`DOMLoaded` 后加 `.ready` 才淡入；棋盘底 `#fff` 改
  `#eef3f9`。去掉 mask 后 SVG 里已无白色矩形。
- 验证：真实浏览器 DOM 检查 masks=0 / 白色矩形=0 / html+body 背景 rgb(11,18,32) /
  白色高光 path=rgb(248,252,255) / ready=true；深色、浅色、棋盘三底截图高光均可见，
